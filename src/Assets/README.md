# Partition Studio brand assets

The logo was generated for this project using the built-in image generation tool on 2026-11-11. It is not a MiniTool/CGSecurity/Microsoft logo. The selected original image has transparent alpha. BrandMark.png is a 512-pixel runtime rendition; AppIcon.ico packages standard Windows icon sizes from 16 to 256 pixels. Resizing/ICO encoding are format adaptations, not a claim of a vector master.

Original project assets are distributed with the project's MIT license. No claim of trademark registration, third-party endorsement or exclusive worldwide originality is made. The generated mark should be reviewed before formal brand registration.

Prompt used for the selected generation: original geometric disk/platter brand mark for Partition Studio; three separated segments, central negative-space hub and a recovery/safety sweep; midnight navy, periwinkle blue and teal; transparent background, no text or existing commercial logos. A refinement was explored but the first generated variant was selected for the runtime asset.
